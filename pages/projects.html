Urban Engines: Baltimore Drift

Team | Unity | 95% code contribution | Group 2D

2025

This game is the first project where I worked collaboratively with others (4 others specifically) to create a game. Furthermore, this game was created in response to B-360's request for a game that was both educational and fun.
Though this was a group project, the rest of my team was art focused. While they did help a little, this left me in charge of most of the code behind the game. The main challenge with this game was surprisingly the physics of the side-scroller (fun) section. In past projects, I would normally have a character that would stop the instant the forward/backward control wasn't being pressed however for this game, we wanted the bike keep moving if the player stopped pressing a directional control.

Pokemon Dragonscale

Solo | WIP

2018

Pokemon Dragonscale is my longest project to date. This game is a passion project that I initially started on Roblox, eventually moving to RPGMaker. The concept is to make a game that successfully merges the 9 regions introduced in the main Pokemon games into 1 game. This is something that I never plan to release officially for legal reasons but one that I work on to understand the process of game design better. Over the years, I've made multiple iterations of the project, with the current iteration being ported to Unity due to the restrictions of RPGMaker.

Ruby Rose

Solo

2024

Ruby Rose is a character from the RWBY series. I implemented a variety of moves for her, the major ones being techniques she used in the show like the gun on her scythe and actually integrated her semblance in the character which wasn't available in the previous version. This project was a favorite of the ones I released because unlike my prior MUGEN releases, I experimented with the AI a lot more and made her favor some actions over others depending on the situation. While not a scoring system which is what I use today, this project marks the turning point in how I approached AI development in general.
