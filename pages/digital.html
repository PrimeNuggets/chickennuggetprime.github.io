Character Nexus

Solo | WIP

2025

My Character Nexus is a local-first character manager built with a Vite/React frontend and a tiny Express backend that mostly stays out of your way. Everything-characters, series, species, tags, power system, etc. lives in browser storage, with the server only handling basics like media uploads, quick links, health checks, and validation. The client uses Wouter for routing, Radix + Tailwind for UI and Zod for shared schemas. It supports deep filtering (species, tags, affiliations, demographics, relationships, zodiac, alignment, combat style, auto-tags), carousel media galleries, birthday/zodiac banners, and a roster builder that lets you assemble characters, add notes, and export the lineup as an image-all without turning into a bloated backend-heavy app.
